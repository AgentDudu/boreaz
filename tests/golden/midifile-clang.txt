# The same four measurements as midifile.txt, taken with the clang-cl tree (see PLAN.md §7).
#
# They have their own file because bit-exact means bit-exact. clang-cl contracts multiply-add
# where the MSVC cl.exe build will not, so the same song renders to samples that differ in the
# low bits, and `fnv1a64` - which is every output sample - moves while `frames`, `peak` and
# `steals` do not. That is the whole difference between the two files, and it is worth checking
# before believing a drift: if `peak` or `steals` ever differ too, the two compilers are not
# disagreeing about rounding, the engine is.
#

#   for f in tests/fixtures/midifile/*.mid; do build-clang/boreaz-render --golden "$f"; done
